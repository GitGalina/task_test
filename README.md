# Привет, я Галина 👋

**Преподаватель и любитель-разработчик.** Пишу инструменты для учебного процесса
с помощью ИИ-ассистентов (Claude Code, OpenCode): от идеи и ТЗ до рабочего
приложения. Продвинутый пользователь Excel — сложные формулы, сводные таблицы,
макросы VBA, дашборды.

## Чем занимаюсь

- Автоматизирую рутину преподавателя: расписания, журналы посещаемости, отчёты.
- Собираю аналитику по тестам и успеваемости студентов.
- Парсю данные из браузера и мессенджеров в удобные Excel-таблицы.
- Делаю образовательные сайты и лендинги, готовлю презентации кодом.

## Как я работаю

1. Формулирую задачу и ограничения (MVP) — часто прямо в Markdown-ТЗ для агента.
2. Проектирую вместе с ИИ-ассистентом, затем реализация и проверка.
3. Тестирую (pytest, ручные сценарии), собираю в .exe или деплою.
4. Документирую: README, инструкции для коллег-преподавателей.
